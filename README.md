# Aplikacja mobilna – System zarządzania personelem 

Projekt został zrealizowany przy użyciu platformy **Expo**  
(https://expo.dev) i utworzony za pomocą narzędzia  
[`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

Aplikacja stanowi część **systemu zarządzania personelem w branży gastronomicznej**

---

Aplikacja została wykonana w technologii **React Native** z wykorzystaniem frameworka **Expo**
i działa na systemach **Android** oraz **iOS**.

---

## Uruchomienie projektu

### 1. Instalacja zależności

W katalogu projektu zainstaluj wymagane pakiety:

```bash
npm install
```

### 2. Uruchomienie aplikacji

Aby uruchomić aplikację w trybie deweloperskim, wykonaj polecenie:

```bash
npx expo start
```

### 3. Przełączenie na Expo Go

W konsoli wybierz opcję:

```bash
Press s │ switch to Expo Go
```

### 4. Instalacja aplikacji Expo Go

Zainstaluj aplikację Expo Go:

-   z Google Play Store (Android),

-   lub App Store (iOS).

### 5. Uruchomienie aplikacji na urządzeniu mobilnym

-   Zeskanuj kod QR wyświetlony w terminalu lub przeglądarce,

-   wybierz opcję Otwórz w Expo Go,

-   aplikacja uruchomi się na urządzeniu mobilnym.

## Wymagania systemowe

-   Node.js (zalecana wersja LTS)

-   npm lub yarn

-   Urządzenie mobilne z systemem Android lub iOS

-   Zainstalowana aplikacja Expo Go
